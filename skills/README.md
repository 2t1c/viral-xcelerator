# Skills

Custom Claude skills that power the agentic path. These stay in their own repos; linked here for reference.

- **viral-longform-x** — `2t1c/viral-longform-x`. Converts podcast/video transcripts into viral longform X posts (GeniusGTX + Goku brand configs, craft references, anti-fabrication checklist).
- **timeline-scroll** — discovers algorithm-surfaced trending posts beyond curated lists.
- **youtube-monitor** — browses YouTube feed/subscriptions for clip-worthy content.

> The agentic path (Claude Code + Skills) is the graduation step. See `../03-ai-powered-creator/agentic/`.

# Editing / QC Prompt

The internal QC prompt taught to the team. Run every draft through it.

```
Replicate the format of the example tweets.

Guidelines:
- Keep each tweet under 280 characters.
- Fix all grammar. Use American English.
- Write at a 6th-grade level in Hemingway's style.
- Put each sentence on its own line, with double (2x) spacing so there's a blank line between sentences when pasted into X.
- Every tweet must give specific, actionable insight readers can't find elsewhere.
- Use bullet points (•) when listing 3+ items, with supporting detail underneath. Order bullets by length (ascending or descending) or by chronology/importance.
- Use specific time references. Instead of "a teenager," say "15."
- Remove all AI-tell vocabulary (realm, delve, captivating, unwavering, explore, revolutionize, etc.).
```

> 80–90% of editing should go to the hook. If nobody gets past it, nothing else matters.

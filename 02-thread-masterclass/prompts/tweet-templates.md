**T1 — Who is {X}?**
```

• Achievement #1
• Achievement #2
• Achievement #3

```

**T2 — The Big Idea**
```
The big idea?
{Insert big idea.}
{The outcome in one sentence.}
Here are the {5}:
```

**T3–T7 — Listicle item**
```
1. {Big idea}
{X} is the foundation of the new world.
• Example 1
• Example 2
• Example 3
{Authority} expects {X} to be a {valuation} market.
```

**T8 — Why this matters**
```
This matters more than ever:
• Reason #1
• Reason #2
• Reason #3
Especially with the rise of {X problem}.
```

**T9 — Problem statement**
```
{X} is the problem. It's causing:
• Pain point 1
• Pain point 2
• Pain point 3
Most solutions don't address the root cause. That's where we step in…
```

**T10 — Our model / solution**
```
At {X}, we are the {describe business}.
Unlike most, we {differentiator}:
• Feature / USP
• Feature / USP
• Feature / USP
```

**T11 — Why it's better**
```
{Create urgency — why act now.}
If you want {benefit}, click the link below:
{Link}
```

**T12 — Author intro**
```
Hi, I'm {X}.
For {Y} years I've helped {Z people} do {thing}.
Now I'm sharing the lessons to {purpose}.
Follow me @{handle} for more…
```

**T13 — Wrap-up CTA**
```
That's a wrap.
If you enjoyed this, {action}.
Comment your thoughts on {topic} below.
```

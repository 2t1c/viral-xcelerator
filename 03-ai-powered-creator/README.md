# AI-Powered Creator

The command center for using AI across the whole program. Every other course teaches a skill; this one shows you how to run that skill with AI.

> **The one rule:** Learn the skill manually first. Then use AI to scale it. If you use the prompts before you understand the craft, you won't be able to tell when the AI gets it wrong — and it will.

---

## Restructure plan (in progress)

The course was originally organized around three "paths" (A: GPT, B: Prompt Suite, C: Agentic). That framing causes confusion because A and B aren't parallel — they run the *same* pipeline on the *same* steps. The GPT is literally the chat-wrapped version of the prompt suite.

**New framing: one pipeline, two modes.**

- **Assisted** — you run the pipeline yourself with AI help (the prompts, optionally wrapped in the GPT)
- **Agentic** — you delegate the pipeline to an agent (Claude Code + Skills)

### New section order

1. **Start Here** — the warning (earn manual reps first), how this connects to the program, the pipeline overview, and the assisted-vs-agentic framing. Replaces the old "pick a path" page.
2. **The Pipeline (core)** — one lesson per step, each holding its prompt. This is the old "Path B," promoted to the backbone. *(see `pipeline/`)*
3. **The GPT (optional quick-start)** — one tool page, repositioned. *(see `the-gpt.md`)*
4. **Personalization & Voice** — voice doc, brand tonality, style-clone prompts. The real differentiator. *(see `personalization-and-voice.md`)*
5. **Agentic (advanced / scale)** — Claude Code + Skills, badged as the graduation step. *(see `agentic/`)*

Then: **See It In Action** (full worked demo) at the end.

### Cleanup before launch

### The one genuine gap
There's no single **"How to work with AI"** lesson — the meta-skill of iterating, giving feedback, and pushing past the first generic draft. Add one short lesson on taste and iteration. It ties the whole course together and reinforces the "learn the craft first" thesis.

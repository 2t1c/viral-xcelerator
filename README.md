## How to best use this repo

Pick the entry point that matches what you are doing.

- **New here?** Start at [`00-start-here/program-structure.md`](00-start-here/program-structure.md), then work the numbered folders in order. Do not skip ahead. The sequence is the fastest path even when it does not feel like it.
- **Writing a thread right now?** Go straight to [`02-thread-masterclass/viral-threads-in-a-box.md`](02-thread-masterclass/viral-threads-in-a-box.md). That is the end-to-end SOP.
- **Using AI to create?** Open [`03-ai-powered-creator/`](03-ai-powered-creator/). It maps every pipeline step to the prompt that runs it.
- **Need a hook, phrase, or prompt fast?** Raid the reference shelves: `swipe-files/`, `prompts-library/`, `fundamentals/`.

### Reading it with Claude or another AI

The repo is public, so you can point an AI assistant straight at it.

- Paste the repo URL (or any file's URL) into Claude and ask it to read or summarize.
- In Claude Code, open a session on the repo and ask questions across the whole archive at once.
- A good starter prompt: "Read the README, then turn the Viral Thread in a Box SOP into a checklist I can follow."

## What this is

Viral Xcelerator turns someone into a **full-stack creator**: able to create content *and* monetize it well enough to live on it. The program is a sequence of courses, each a milestone. This repo holds the written backbone of all of them in one navigable place.

The course sequence:

```
Anonymous Account  →  Thread Masterclass  →  Monetization  →  Personal Branding  →  Scaling
                                                  │
                                    ┌─────────────┴─────────────┐
                              Digital Products            Service-Based
```

The **AI-Powered Creator** course runs alongside the whole thing — it's the command center for using AI at every step.

## How to navigate

- **Building a page from scratch?** Start at `00-start-here/program-structure.md`, then work the numbered folders in order.
- **Writing a thread right now?** Go straight to `02-thread-masterclass/viral-threads-in-a-box.md` — that's the end-to-end SOP.
- **Using AI?** `03-ai-powered-creator/` maps every pipeline step to its prompt.

---

## The one rule (applies everywhere)

> Learn the skill manually first. Then use AI to scale it.

If you reach for the prompts before you understand the craft, you won't be able to tell when the AI gets it wrong — and it will get it wrong.
